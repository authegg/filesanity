# Harvest

Every fix made by hand after the agent declared done is a rule missing
from the studio layer. Log each one here as a rule, not a complaint.

Format: `- [date] rule: ... (came from: what was fixed)`

At project end, move these into the studio layer's Notes section. A rule
that appears three times across projects gets promoted into standards.
Then append one row to `SHIPPED.md`, fields as in its header, from
`DECISIONS.md` and the critic's Q1 caption.
